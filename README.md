# Blogicum

Blogicum - социальная сеть для публикации личных дневников.
Это сайт, на котором пользователь может создать свою страницу и публиковать на ней сообщения («посты»). 
Для каждого поста нужно указать категорию — например «путешествия», «кулинария» или «python-разработка», а также опционально локацию, с которой связан пост. 
Пользователь может перейти на страницу любой категории и увидеть все посты, которые к ней относятся.
Пользователи смогут заходить на чужие страницы, читать и комментировать чужие посты.

## Стек технологий

- **Python**
- **Django**
- **HTML**
- **CSS**
  
## Как развернуть проект

1. Клонируйте репозиторий и перейдите в директорию проекта:

   ```bash
   git clone https://github.com/mistlenok/blogicum.git
   cd blogicum
   ```

2. Cоздайте и активируйте виртуальное окружение:

```
python3 -m venv venv
```

* Если у вас Linux/macOS

    ```
    source env/bin/activate
    ```

* Если у вас windows

    ```
    source env/scripts/activate
    ```

```
python3 -m pip install --upgrade pip
```

3. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```
4. Выполните миграции:

```
python3 manage.py migrate
```

5. Запустите проект:

```
python3 manage.py runserver
```
